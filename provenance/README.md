# Provenance records

These files record how Nearzero 1.0 was built as a clean-room implementation, and the results of the provenance scans run along the way:
- `M0.md` to `final.md` cover the first build;
- `rounds-2-3.md` covers the later parity rounds;
- `LOG.md` lists every piece of work, with who did it and what it was built from.

The public repository starts from a single commit. The commit hashes these reports name belong to the development history, which Nearzero Systems keeps.
